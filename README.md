## 🚀 Running PurePulse Locally

PurePulse is a static website, so getting it running locally is simple.

### 1. Clone the repository

```bash
git clone https://github.com/Mattjhagen/PurePulse.git
```

### 2. Enter the project

```bash
cd PurePulse
```

### 3. Open the website

You can open `index.html` directly in your browser.

For local development, using a simple HTTP server is recommended.

### Python

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

### VS Code

You can also use the **Live Server** extension and launch `index.html`.

## ⚡ Performance Matters

A website can be gorgeous and still be bad.

Huge dependencies, unnecessary scripts, oversized assets, and complicated frameworks can turn a simple business website into something painfully slow.

PurePulse favors:

**Less complexity → less overhead → faster experiences.**

The goal isn't to use the most technology.

The goal is to use the **right technology**.
